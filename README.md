# Employee Attrition Analysis

## Project Overview
This project analyzes employee data to understand employee attrition patterns and identify factors that may influence employees to leave an organization.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `employee_attrition_analysis.ipynb` – Python analysis and visualizations
- `Employee_Attrition_Analysis.csv` – Original dataset
- `cleaned_employee_attrition.csv` – Cleaned dataset
- `Employee_Attrition_Analysis_Final_Report.pdf` – Project report

## Key Objectives
- Clean and preprocess employee data
- Analyze employee attrition patterns
- Explore factors related to employee turnover
- Visualize findings using charts

## Conclusion
This project demonstrates the use of Python data analysis and visualization techniques to explore employee attrition.
